# Проверка внешних данных

Выгрузка ChEMBL включает 6148 измерений, однако отдельное IC50 или CC50 не задаёт SI.
Из 260 кандидатных пар 108 имеют точные отношения `=` и совпадающую известную клеточную линию;
это условие фильтрации, а не доказательство совместимости.

Для пяти записей из одной публикации выполнена дополнительная сверка Table 1 и определения SI:
https://pmc.ncbi.nlm.nih.gov/articles/PMC6335999/ , DOI 10.1039/C8MD00442K.
Значения — опубликованные средние, экспериментальные интервалы остаются в источнике.
Контекст assay взят из ChEMBL. Результат: `data/external/external_curated.csv`.

Все пять parent-структур уже находятся в train или test. Они не добавлены к baseline и
не используются для вычисления test-метрик. Запись для смеси диастереомеров оставлена без одобрения.
SI вычислен из сопоставленных средних; округлённый SI публикации сохранён отдельной колонкой.
Независимая ручная проверка этих строк командой пока не подтверждена. До её завершения
пары остаются справочными записями и не добавляются в обучение.

```bash
python scripts/review_pairs.py
python scripts/curate_reference.py
```

Следующий полезный шаг — проверить другие публикации из очереди и найти новые структуры с сопоставимым SI.
Дальнейший эксперимент должен показать, помогает ли такой набор на неизменной локальной валидации.
Наличие DOI у каждой строки не делает её независимым экспериментом: проверяйте повторные статьи,
контрольные соединения и совпадения химических серий.
