# Локальный комплект для сдачи

## Версия и назначение

Базовый опубликованный коммит: `4f48d61995a211f779300eb96d920c9e9cdac28a`.
Команда NLP, Nuclear IT Hack 2026: регрессия SI VACV по SMILES, метрика MSE в исходной шкале SI.
Модель и данные сохранены. При подготовке комплекта новое обучение baseline не запускалось.
Документы комплекта и запись внешнего аудита подготовлены после указанного коммита.

Комплект содержит приватные данные соревнования и предназначен для локальной работы и согласованной
передачи при сдаче. Публикуемый исходный репозиторий и локальный комплект — разные наборы файлов.

## Фактические обучающие данные

Единственный вход обучения baseline — `data/raw/train.csv`, SHA256
`239efa4b3aa667b3681f6e1062d86ca5b0ba441364b8f2b894b4c428e272ba81`.
В модель передаются только признаки из `SMILES`; целевая колонка — `SI VACV`.
CC50, IC50, их пропуски/отношение и остальные метаданные не являются признаками.

Таблица `training_dataset.csv` — представление тех же 320 исходных строк для сдачи;
SMILES и SI сверены с train. Концентрации оставлены как исходные измерения для аудита.
DOI исходного train не предоставлены, поэтому все 320 DOI в этой таблице пустые.
Метки SI=10000 и нулевые метки сохранены без изменений.

## Разделение проверок

Ранее выполненные собственные проверки: Windows / Python 3.12.10, новая отдельная .venv, одно обучение в чистой
локальной папке, predict и 56 тестов. Отдельно проверялись опубликованные исходники, сохранённая
модель, порядок index и реальный экспорт Streamlit. Эти результаты находятся в Windows-отчётах.

При сборке этого комплекта повторно выполнен `scripts/verify_delivery.py` из его собственной папки:
**56 тестов прошли за 11,29 с**, загрузка модели, экспорт 597 строк, порядок index и контрольные суммы
проверены. Нового обучения baseline не было. В `reports/package_check/preparation_context.json`
пояснено, что поле `full_retraining` сырого отчёта проверяет ранее сохранённое воспроизведение,
а поля публикации не являются запросом к GitHub или Kaggle.
Отчёты ранних инженерных этапов сохранены как история: их промежуточные числа тестов и статусы
публикации относятся к моменту записи. Итоговый статус приведён здесь и в `verification_summary.json`.

Внешний аудит: владелец проекта сообщил об успешном новом Linux-обучении опубликованного
коммита 4f48d61, 597 прогнозах, 56 тестах, воспроизведённых метриках и максимальном отличии
3,64e-12. Это записано как `reported_success`, отдельно от собственных проверок.
Исходные внешние логи, версии окружения, таблица метрик и файлы внешнего запуска не приложены.
Число 3,64e-12 сохранено с сообщённой округлённой точностью; детали среды не выдуманы.

Локальный raw MSE RF seed=42: compound **14 573 172,262681**, scaffold **20 682 986,252401**.
Внешнее сообщение не детализирует объём сравнения дополнительных кандидатов; известные отличия
четырёх исследовательских моделей между платформами остаются явно отмеченными.

## Оставшиеся незакрытые пункты

1. В материалах нет подтверждения принятия финального CSV Kaggle и реального score.
   Локальная CV и внешнее воспроизведение не являются результатом соревнования.
2. Сам комплект ещё не отправлен в канал сдачи; commit/push новых документов выполняет команда.
   Способ передачи приватных CSV и моделей необходимо согласовать с правилами соревнования.
3. Объяснение 81 метки SI=10000 и двух нулевых SI от организаторов не получено.
4. Расширение обучения новыми подтверждёнными внешними SI не выполнено. Пять имеющихся пар
   не являются новыми структурами, ручное подтверждение курации не завершено.
5. Для полной документальной доказательности внешнего аудита желательно приложить исходные
   test log, metric table и environment report; пока имеется сообщение владельца проекта.
6. Выбор модели и оценка используют одни folds; независимые интервалы и клинические выводы не заявляются.
7. DOI исходных 320 обучающих строк отсутствуют в предоставленных данных; их происхождение
   можно дополнить только после получения достоверного сопоставления.

Новых экспериментов, сбора данных или изменения официальных меток при сборке комплекта не выполнялось.
